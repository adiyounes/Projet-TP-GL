# Dairy Products Management System

A Java application for managing a dairy production and sales company, built as a software engineering university project.

## What it does

- **Product catalogue**   add, update, remove and search dairy products (milk types, cheese, yogurt, butter, cream, concentrated milk)
- **Pricing**   calculate sale prices based on production cost, desired margin, and VAT
- **Customer management**   manage reseller and regular customers with different pricing rules
- **Sales operations**   record sales transactions, generate invoices, send invoices by email
- **Sales reporting**  sales journal, monthly reports, comparison against sales targets with automatic alerts
- **Authentication** role-based access for sales agents, commercial agents, and directors

## Roles

| Role | Permissions |
|---|---|
| Sales agent | Manage catalogue, record sales, manage customers |
| Commercial agent | Set product prices |
| Director | View sales reports, set sales targets |

## Stack

| Component | Technology |
|---|---|
| Language | Java |
| paradigm | Object-Oriented |

University software engineering project (Génie Logiciel)   focuses on OOP design, class hierarchies, and system modelling.
